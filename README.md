# API Handling

A full-stack application demonstrating API integration between a React frontend and an Express.js backend. The project focuses on handling HTTP requests, fetching data, managing API responses, and displaying them in a user-friendly interface.

## Features

* REST API integration
* React frontend
* Express.js backend
* Axios for API requests
* Loading state handling
* Error handling
* Clean project structure
* Responsive UI

## Tech Stack

### Frontend

* React.js
* Vite
* Axios
* CSS

### Backend

* Node.js
* Express.js
* CORS

## Installation

### Clone Repository

```bash
git clone https://github.com/rakheebshaikh906-droid/Api-Handling.git
```

### Install Dependencies

Frontend

```bash
cd frontend
npm install
npm run dev
```

Backend

```bash
cd backend
npm install
npm start
```
